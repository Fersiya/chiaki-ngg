# [chiaki-ng](https://chiaki-ng.github.io/chiaki-ng/)

**chiaki-ng** — проект с открытым исходным кодом для удалённой игры на PlayStation. Это развитие оригинального Chiaki с дополнительными возможностями и дальнейшей поддержкой.

Документация, новости и дополнительная информация доступны на [официальном сайте проекта](https://chiaki-ng.github.io/chiaki-ng/).

## Сообщество

- [Discord-сервер сообщества chiaki-ng](https://discord.gg/tAMbRuwXDH)

## Официальные загрузки

Скачивайте chiaki-ng только из официальных источников:

- [GitHub Releases — установщики и архивы](https://github.com/chiaki-ng/chiaki-ng/releases)
- **winget:** `winget install --id=StreetPea.chiaki-ng -e`

Сторонние сайты, предлагающие загрузить chiaki-ng (например, chiaki-ng.com), не относятся к проекту. Мы не можем гарантировать безопасность и подлинность размещённых там файлов.

## Платформа

Этот форк поддерживается и собирается для **Windows**. Актуальные сборки Windows доступны на странице GitHub Releases или через winget.
